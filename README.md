# 🌤️ Weather App

This is a modern and fully responsive **Weather App** designed to check real-time weather for any city with a clean and professional UI. The app focuses on user-friendly navigation and quick weather updates.

This project demonstrates frontend development skills and working with real-world APIs.

---

## 🌍 Features

- Search weather by city name  
- Displays temperature, weather condition, humidity, and wind speed  
- Fully responsive layout (Desktop, Tablet & Mobile)  
- Clean and intuitive user interface  
- Fast and lightweight  

---

## 📲 Real-Time Weather Data

The app fetches **real-time weather data** from the **OpenWeatherMap API**.  
Users can quickly see the weather conditions for any city worldwide.

Benefits:
- Accurate weather updates  
- Easy to use  
- No backend required  
- Ideal for showcasing frontend skills  

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript (ES6)  
- OpenWeatherMap API
